# Apple Health API

Python Azure Function that accepts Apple Health exports from the React Native app and stores each payload in Azure Cosmos DB for NoSQL.

## Endpoint

`POST /api/health-export`

The request body should match the app payload:

```json
{
  "schemaVersion": 1,
  "exportType": "complete-day",
  "localDate": "2026-05-02",
  "personId": "james",
  "exportedAt": "2026-05-03T10:00:00.000Z",
  "window": {
    "start": "2026-05-02T00:00:00.000Z",
    "end": "2026-05-03T00:00:00.000Z"
  },
  "platform": "ios",
  "metrics": {},
  "totals": {}
}
```

Successful response:

```json
{
  "ok": true,
  "id": "james:2026-05-02:complete-day",
  "personId": "james",
  "localDate": "2026-05-02",
  "exportType": "complete-day"
}
```

## Cosmos DB shape

Each export is stored as one document. The document keeps the full original payload and adds:

- `id`: `<personId>:<localDate>:<exportType>`
- `userID`: copied from `personId` for the Cosmos partition key
- `receivedAt`: UTC timestamp generated by the API

Create the Cosmos container with partition key `/userID`. Using a stable document ID means retries and repeated `today-so-far` exports update the existing document instead of creating duplicates.

## App settings

Copy `local.settings.json.sample` to `local.settings.json` for local development and fill in:

- `COSMOS_ENDPOINT`
- `COSMOS_KEY`
- `COSMOS_DATABASE`
- `COSMOS_CONTAINER`
- `HEALTH_API_TOKEN`, optional. If set, requests must include `Authorization: Bearer <token>`.

In Azure, add the same keys under Function App > Settings > Environment variables.

## Local development

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
func start
```

If Core Tools starts with `No module named 'azure.cosmos'` on Windows, run it with the virtualenv packages on `PYTHONPATH`:

```bash
$env:PYTHONPATH = "$PWD\.venv\Lib\site-packages"
func start
```

Health check:

```bash
curl http://localhost:7071/api/status
```

Example post:

```bash
curl -X POST http://localhost:7071/api/health-export ^
  -H "Content-Type: application/json" ^
  -H "Authorization: Bearer <token>" ^
  -d "{\"schemaVersion\":1,\"exportType\":\"complete-day\",\"localDate\":\"2026-05-02\",\"personId\":\"james\",\"exportedAt\":\"2026-05-03T10:00:00.000Z\",\"window\":{\"start\":\"2026-05-02T00:00:00.000Z\",\"end\":\"2026-05-03T00:00:00.000Z\"},\"platform\":\"ios\",\"metrics\":{},\"totals\":{}}"
```

## Deploy

From this folder:

```bash
func azure functionapp publish <function-app-name>
```

Use the deployed function URL in the React Native app. If `HEALTH_API_TOKEN` is set, also enter that token in the app so it sends the bearer header.

## References

- Azure Functions Python v2 uses decorators in `function_app.py`.
- Azure Cosmos DB Python SDK supports `container.upsert_item(...)` for insert-or-update writes.
